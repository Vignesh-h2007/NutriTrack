Project Core Objectives
🧠
Algorithmic Recommendation Engine

Automated computation of Basal Metabolic Rate (BMR) via the Mifflin-St Jeor formulation and Total Daily Energy Expenditure (TDEE), adapted dynamically to user lifestyle and fitness goals.

🩺
Preventative Healthcare Constraints

Personalized clinical rule filters for users presenting condition indicators such as Diabetes, Blood Pressure, Cardiovascular conditions, and Kidney parameters to eliminate harmful dietary items.

📊
Interactive Data Visualization

High-performance HTML5 Canvas & Chart.js progress trackers, real-time hydration alarm monitors, workout streak counters, and weekly calorie intake analytics for comprehensive user compliance.

🧩
Object Oriented Programming Implementation
ENCAPSULATION

Secure Entity Models

Entities like User, MealLog, and WorkoutSession maintain private member state with strict validation in mutator and accessor methods.

INHERITANCE

Modular Hierarchy

Re-usable abstract controller servlets and service layers eliminate code redundancy and provide shared session validation and JSON serialization.

POLYMORPHISM

Dynamic Strategy Processing

Flexible activity multiplier strategies and calorie deficit models dynamically compute varied outcomes according to user health objectives.

ABSTRACTION

Clean Service Contracts

The presentation layer interacts exclusively with high-level service contracts (e.g. UserService, WorkoutService), decoupling business logic from storage.
